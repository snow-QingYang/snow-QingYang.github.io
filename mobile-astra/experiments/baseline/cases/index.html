怎么看这些记录

  • 逐次调用：左侧完整连续视频，右侧全部方法的参数与原始返回，包含感知和文件读取。
  • 信息清单：直接跳到任务进度、接触反馈、位置查询等实际进入 Agent 上下文的返回。
  • 初始提示 / 事件顺序 / 原始文件：核对输入、公开消息、图片和来源，下载原始记录。

环境动作编号与工具调用序号不同。视频动作边界由步数和返回图像核对，不是原始逐帧工具时间戳。
