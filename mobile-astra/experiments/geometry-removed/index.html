这次移除了什么

两种主动三维查询

从 Agent 工具列表中移除 back_project_batch 和 query_world_map，不能再通过它们取得像素对应的世界坐标或按空间范围筛选点簇。

初始 Prompt 和工具说明同步去掉调用要求，改为查看当前 RGB 图像；提醒只使用当前可用的方法。

仍然保留的信息与控制

RGB 图像、末端与底盘状态、task_progress（含部分距离）、抓持／接触反馈、成功信号、评分源码访问与历史记忆。

move_to、scripted_grasp、navigate_to 和相对移动仍可用；VLA、控制流程和原生任务评分保留。

“移除深度”在这里具体指移除这两个几何查询入口。模拟器内部仍生成深度和 world map 文件；文件、记忆和 shell 权限没有额外收紧。本实验没有叠加 DA3、任务进度移除或接触反馈移除，不代表所有几何真值通道都被隔离。

结果核验与比较限制

160 局结果均有效，并与保存的环境原生成功信号核对。模型、响应与时间预算、VLA 配置及选用记忆与 E01 对齐；具体哈希和工具日志检查见详细数据。

扫描全部 160 局日志中的 5,263 次已记录 MCP 工具调用，两种被移除几何工具的调用数为 0。已记录的文件读取参数和原生命令文本中，也未命中所检查的几何文件／位置访问模式；检查不覆盖间接脚本、历史记忆或未记录的操作。

初态检查发现 10 对机器人状态存在大于 10−6 的差异，2 对任务文本不同。检查不覆盖全部物体状态，场景 seed 也未同时固定独立 VLA 的动作采样。

结果支持的描述是：这次移除查询的批次成功率较低，净下降主要发生在 Seen。是否由特定几何查询缺失导致，需要结合轨迹并用成对重复实验验证。
