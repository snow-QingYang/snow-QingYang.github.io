移除的是两个查询入口

不再向 Agent 注册

back_project_batch：从指定相机像素查询世界 XYZ 坐标。

query_world_map：按高度或 XY 区域过滤世界坐标图，再返回聚类位置。

评测 prompt 删除了这两个工具的说明、示例与调用要求；观测方法的说明同步调整。

仍然保留

模拟器内部深度和世界坐标图、相机标定、本体状态、接触反馈、task_progress（可能包含距离）、成功与终止信号、评分规则访问、历史记忆。

VLA 输入、权重、控制与预算保留原设置。move_to、scripted_grasp、navigate_to、move_delta 仍可接收 Agent 给定的位置或位移。

没有使用 DA3，也没有叠加 NoTaskGT 或 NoContactGT。本实验关闭主动几何查询入口；不是移除模拟器内部 depth，不是完全无几何真值，也没有建立文件／RPC 隔离。
