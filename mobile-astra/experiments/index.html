统一记录口径

  • 结果：以环境最终判定为准，成功与失败都计入；中断或配置不符单独记录。
  • 路径：区分 VLA 直接完成、先准备再调用 VLA、VLA 后有解析动作介入。介入后成功是轨迹分类，不自动证明介入导致成功。
  • 可比性：列出模型、记忆、预算、初始状态检查和仍然可用的真值通道。
  • 证据：详细分析保留逐局 JSON / CSV、来源哈希与统计脚本；案例嵌套在所属实验目录。
