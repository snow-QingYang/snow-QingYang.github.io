统一记录口径

  • 结果：以环境原生判定为准，成功与失败都计入；各实验注明累计成功或终态评分。E12 使用动作块内累计成功，成功后在块末自动停止。中断或配置不符单独记录。
  • 路径：区分 VLA 直接完成、先准备再调用 VLA、VLA 后有解析动作介入。介入后成功是轨迹分类，不自动证明介入导致成功。
  • 可比性：列出模型、记忆、预算、初始状态检查和仍然可用的真值通道。
  • 证据：详细分析保留逐局 JSON / CSV、来源哈希与统计脚本；案例嵌套在所属实验目录。

完成判定实验如何对应

E03 隐藏 task_progress 并限制文件读取，但仍提供原生成功反馈、保留 VLA 成功早停。E06 基于 No task progress 继续移除成功／终止反馈和早停，不生成评分源码文件；几何、接触与历史记忆保留。

Agent 的 43 次成功声明只有 28 次与最终评分相符，另有 1 次环境成功但未调用 finish；因此 E06 的成绩是 29/160，不是自报成功次数。

几何实验如何对应

E01 保留原版三维查询，E02 用 DA3 深度提供同样的查询，E05 移除这两个查询接口。三组均保留其他任务反馈；E05 没有叠加 E03 / E04。

已有 Sol 模型比较放在 E01 的补充分析；两模型记忆不同，不能当作纯模型消融。
