设置与核验范围

历史任务与全局记忆不被选择或提供；prompt 明确说明无历史记忆；read_text_file 拒绝读取记忆文件。保留本局历史、模拟器几何、接触、任务进度、成功信号、评分源码访问与 VLA 原生成功早停。

两组 320 个结果均有效，并与各自最后一条保存观测的原生成功信号一致。全部 160 个 NoMemory 结果的记忆审计为 ok，选中与已读文件均为空；CLI 退出码均为 0。

进一步审计了 160 条流式轨迹、337,744 个 JSONL 事件，未发现解析错误。84 局中有 364 条原生 shell 命令（340 条完成、24 条失败）；未观察到历史任务／全局记忆的读取或读取尝试。160 个记忆读取日志总计 0 字节。

源码搜索／读取发生在 24 局中，另有 AGENTS 与本局文件读取。这些权限按 baseline 保留，包括 PrepareCoffee 和 PanTransfer 的环境源码。审计还记录了 2 条缺少完成事件的 VLA 工具调用、1 次可重试流式错误；160 个 Planner 轮次均有完成事件。

14/160 对初始机器人状态最大差超过 1e-6；按逐值完全相等比较有 23 对不同。5/160 对初始任务文字不同。未检查全部场景物体或匹配独立 VLA 动作采样。

底层记忆加载器仍可能读取既有语料后返回空选择，因此不能声称整个程序没有文件读取。记忆审计也不等于所有 shell 与文件通道都被隔离；原有源码读取仍允许。每个任务只有 5 个 seed、每种设置只运行一轮。这里报告配对差异，不把单局结果变化当作记忆作用的因果证据。
