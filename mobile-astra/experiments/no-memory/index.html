移除与保留

移除历史记忆

不选择、不提供以前积累的任务记忆或全局记忆。评测 prompt 明确说明没有历史记忆；共享文件工具 read_text_file 拒绝读取记忆文件。

本局已经发生的对话、观测和动作历史仍然保留。底层记忆加载器仍可能验证、读取既有语料后返回空选择；这些内部读取不向 Agent 提供历史记忆。

其他部分对齐 baseline

保留几何查询、接触信息、task_progress、success、成功判据源码及其他原有文件访问权限。

保留 VLA 输入、权重、控制和预算，以及原生成功触发的 VLA 提前停止。

这是历史记忆消融，不是无真值实验，也不是文件系统沙箱。NoMemory 与 E03 NoTaskGT 恰好都为 41/160，但移除的信息不同。

核验范围

两组 320 个结果都与各自最后一条观测的原生成功信号一致；NoMemory 的 160 个进程均正常退出。所有 NoMemory 结果的记忆审计都报告选中文件、读取文件为空。另审计了全部 160 条 Agent 轨迹的 337,744 个 JSONL 事件，以及 84 局中的 364 条原生 shell 命令；未发现读取或尝试读取历史任务／全局记忆。

160 对初态中，14 对机器人状态最大差超过 1e-6，5 对任务文字不同；没有核验全部场景物体，也没有固定独立 VLA 动作采样。这里只做任务名与 seed 的配对比较。

这是已记录轨迹的审计，不是操作系统访问隔离证明；底层仍可能为验证而读取记忆语料。原有源码读取仍允许且实际发生，包括环境物理属性与任务判据。
