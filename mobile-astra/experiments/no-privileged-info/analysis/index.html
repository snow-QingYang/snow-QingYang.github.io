初态可比性

相同任务名和 seed 不保证所有初始条件都完全相同。与仅移除几何相比，132/160 对的机器人状态、任务文字、三路初始 PNG 和相机 metadata 全部精确相等。在该事后诊断子集中，组合移除 31/132，仅移除几何 32/132；它不是完整评测，也不能作为因果估计。

140 对机器人状态逐值相等；另有 5 对最大差不超过 1e-6，15 对存在明显位置差异。5 对任务文字不同。少量 PNG 只差一个灰度级的几个像素，不能据此称场景不同。

实际输入与审计

保留 native success / termination、成功早停、机器人精确 EEF / base / gripper 状态、RGB，以及 counter≈0.9 m / reach≈0.8 m 等固定先验。Agent 没有收到数值相机 K、R/t、pose、FOV；calibration_frame 只是标签。完整信息矩阵 · Planner 与 VLA 的不同相机组合。

160 局的 4,632 次已完成工具返回及 4,327 条保存观测中，没有发现被移除的任务进度或四个接触字段；几何查询、文本读取、原生 shell 调用均为 0。所有记忆列表为空，success_criteria 文件为 0，最终评分交叉核验无不一致。

内部 depth / world-map / camera metadata 仍生成保存；深度 / world-map NPZ 默认仅保留最近 25 步，RGB 和 metadata 不按此窗口清理。既有 memory 语料也仍在磁盘，但本次选择与读取为空。文件工具限制与轨迹审计不构成 OS 沙箱；本页不声称全部真值被删除。
