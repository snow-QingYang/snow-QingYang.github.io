哪些信息不再给 Planner

信息 / 方法E08 · 提供位姿坐标E09 · 不提供位姿坐标
末端与底盘位姿返回实测位置与姿态不返回；初始、当前、历史和动作后观测均隐藏。
夹爪状态返回夹爪开度与 held_apart 启发式不返回 gripper_qpos、robot0_gripper_qpos、held_apart。
实际移动与端点误差保留不返回 final_dist、base_moved、moved、peak_lift、base_drift。
动作执行诊断保留不返回动作 ok / stuck / status、实际执行步数与 chunks、动作耗时、vla_desync 等。正常动作结果为空。
主动三维几何back_project_batch、query_world_map 均不注册；没有 DA3 或 SceneGraph 替代方法。
历史 memory不选择、不展示、不读取历史任务 / 全局记忆；本局对话与动作历史保留。启动时仍可内部验证已有语料。
任务进度与接触标签不返回 task_progress，也不返回 grasp_contact、grasp_obj、grasped、grasp_detected。
成功判据源码不生成 success_criteria.md；RPent 文本读取工具拒绝读取。
成功与终止信号保留 success、robocasa_terminated。VLA 成功早停与最终原生评分保留。
RGB 与任务描述保留 RGB、camera / role 标签、图像索引、任务文字、本局历史和 Agent 自己发出的动作参数。
错误与固定先验保留工具错误，以及台面约 0.9 m、机械臂可达约 0.8 m 等固定 prompt 先验。
VLA / controller 内部输入原有机器人 proprioception、控制执行逻辑、VLA 图像与历史继续使用；模拟器物理不变。

输出限制同时作用于保存的状态 / 动作结果，以及 view_env_state().log.result 的当前和历史回读。初始尚无动作时，log.result 可以为 null。

Agent 仍可以给 move_to、navigate_to 等动作填写 XYZ / XY，也可以指定夹爪命令或 steps。这些是它自己发出的参数，不是模拟器返回的位置、开度或实际执行量。finish(status=...) 也属于 Agent 自己的声明。

该设置不是严格的“只有 RGB”，也不是全部无真值：原生 success、任务文字、自己的命令、图像索引、错误和固定先验仍可见。限制的是 Planner 输入；不移除 VLA 和控制器所需的内部状态。

160 局结果怎样核验

最终 160/160 局均通过结果校验，运行源码与冻结哈希一致；所有 wrapper 与 launcher 的最终退出码为 0。评分按模拟器原生结果统计，正常结束但任务未成功的 133 局照常计入分母。

上下文审计覆盖 4,353 次已完成工具调用、4,045 次正常观测返回及 4,047 条保存状态：43 个隐藏反馈字段命中为 0，几何查询、文件读取与原生 shell 调用均为 0。所有保存 state 为空；另有 2 条预算结束时的 tool_cancelled 保存标记，不属于正常完成的观测返回，不能说所有保存动作结果都为空。

核查了全部 640 份运行、启动、模拟器和 VLA 日志，未发现 CUDA / OOM / EGL、内存异常或环境—VLA 通信错误混入最终结果。日志保留 4 次历史 API 断流重连记录。

此前因显存争用中断的 5 局已重新执行，最终均正常结束但任务未成功；这些失败计入本次结果。更早的 16 份受基础设施错误污染的旧结果已排除，原始记录保留，由有效重跑结果替代。

该审计确认最终记录中没有上述异常证据，并不证明运行期间完全没有资源争用。逐局 JSON / CSV 仅发布筛选后的结果、统计和哈希。
