实验设置

隐藏的信息

初始观测、动作后的自动观测和 view_env_state 不返回 task_progress。read_text_file 仅允许读取记忆目录内的文件，因此不能用它访问当前 episode 的 success_criteria.md 和 states.json。

Prompt 同步去掉查看任务进度、读取评分源码的要求。这三项共同构成 NoTaskGT 设置。

保留的信息与配置

原版模拟器深度、几何查询、相机标定、机器人本体状态、接触／抓持反馈、success 与 robocasa_terminated 均保留；环境内部评分和 VLA 成功提前停止仍然有效。

未使用 DA3 或 NoContactGT。两组使用相同模型与 VLA；100 个模型响应 / 3600 秒预算，VLA 每次最多 40 × 8 仿真步。

使用的 95 个任务／全局记忆文件与 E01 重跑记录的 SHA-256 全部一致；内容仍是原有记忆。文件读取限制针对这个工具，不构成对所有原生 Planner 能力的隔离保证。查看真值访问说明 →
