对照范围

保留模拟器几何查询、相机标定、机器人状态、接触反馈和官方任务记忆。本实验没有叠加 DA3、移除接触或移除几何工具。

Agent 观测隐藏 task_progress、success、robocasa_terminated，不生成 success_criteria.md。模拟器内部保留原有判据调用以维护任务状态，最终评分不反馈给正在运行的 Agent。

E03 已发布批次早于 No task progress 后续取消生成成功判据文件的代码修订。E06 还修改了成功反馈与 VLA 提前停止行为，不能把两组差值解释为只切换一个开关的效果。这里审计的是结果字段、配置和完整性，未重新逐条审计全部 Agent 工具轨迹。
