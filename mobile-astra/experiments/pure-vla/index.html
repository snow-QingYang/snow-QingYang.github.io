改变了什么，保留了什么

完整任务直接交给 VLA

每局使用原生完整任务指令，不由语言模型拆解或改写子任务；没有 move_to、scripted_grasp 等 Planner 调度的额外动作，也不读取跨任务 memory。

模型不接收三维查询结果、模拟器接触标签、task_progress 或 success 反馈来选择动作。success 仍供评测端评分与停止使用。

模型需要的观察和控制保留

左、右、腕部三路 256 × 256 RGB；末端与底盘位置／姿态、夹爪位置。模型可自行移动底盘。Pure VLA 仍使用本体状态。

视频历史索引 [-6,-4,-2,0]，state [0]；预测 16 步、执行前 8 步再观察，4 次去噪迭代。实际 checkpoint 配置为 use_memory=false、RTC 关闭；每局重置一次 policy。

成功如何判定

本次确定成功 25 局，失败 135 局。每个原生动作读取模拟器任务成功信号；动作块中曾出现成功就记为 any_success=true，在该动作块结束时自动停止并计成功。这与固定 RLDX 官方 rollout 的评分规则一致。

自动停止在动作块返回边界检查，最多相隔 8 个动作；不是首次成功的单步立即打断。成功标签不进入模型观察，达到任务 horizon 时只执行剩余预算。

终态诊断记录（不改变成功计数）

final_state_success 是 reset 前终态的额外记录，不是本实验的成绩。25 个成功结果中有 1 局在动作块内达到成功、结束时终态不成功；该局仍计成功，160 局主评分不变。

  • MakeIceLemonade / seed 1：第 1937 个原生动作首次成功；第 1944 步动作块结束时终态不成功。该局按评测规则计为成功。

预算、seed 与运行核验

每任务 horizon 固定为 1200–4350 个原生动作，来源于 RLWRLD/RLDX-1 固定版本的任务预算。全组实际执行 369,632 个原生动作，46,249 次模型调用；逐局实际耗时总和约 11.32 小时，不含队列空闲等待。

每个 task / seed 单独启动环境；构造与全局环境 RNG 显式使用 seeds 1–5；复用构造期第一次 reset 的观察。160 局均验证只有一次 native reset，没有录像 wrapper 的 seed 重写。模型采样 seed 由 task / seed 独立确定。

正式评测前，ScrubCuttingBoard seed 1 的 32 步真实模型冒烟通过。调度只在允许的空闲卡上派发；每局 7200 秒基础设施保护、最多 3 次基础设施尝试，普通任务失败不重跑。最终 160/160 结果通过冻结版本校验器，missing / rejected / errors 均为空。

实际运行使用锁定的 RLinf 兼容 fork；这是固定模型、成功语义和动作预算下的复测，不宣称与原作者默认 50 局评测具有相同初态或样本量。完整版本与比较限制见 manifest。
