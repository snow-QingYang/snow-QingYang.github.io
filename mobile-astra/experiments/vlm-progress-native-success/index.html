这次替换了什么

信息 / 行为E10 的来源与规则
task_progress独立 Terra 看图估计，source=vlm；固定条件逐项返回 satisfied / unsatisfied / unknown。
success / robocasa_terminated模拟器原始值，success_source=native；成功时告知 Agent。
动作与结束VLA 在原生成功后提前返回；finish(success) 检查最新原生成功，即使 VLM 未确认也可结束。
保留的信息原版几何查询、深度/world map、接触反馈、历史任务/global memory、原 VLA 输入和动作工具。
VLM 请求输入任务文字、固定条件、前次视觉判断、当前/前次观测的 RGB；不传模拟器当前进度、成功值、深度、动作结果、接触真值或 memory。
最终成绩result.json.success，与最后原生状态逐局核对。

VLM 看哪些图

当前时刻的左侧 agentview、右侧 agentview_right、底座前下视角 navview、腕部 wrist，共四张 RGB。初始判断发送 4 张图；动作后同时带上前次观测，共 8 张。navview 会随底座移动，实际画面也可能包含台面和橱柜。

初始化和每次完整动作调用后判断一次，重复查询只读缓存。外层 Agent 原有三路观测以及 VLA 的左/右/腕部输入保持原样。

对照与解释边界

与 E03 按 task/seed 配对：20 局都成功、24 局仅 E10 成功、21 局仅 E03 成功、95 局都失败。本次导出未完整核验对照组初态一致性，也未固定 VLA 随机采样。

E10 比 E03 增加固定条件知识及额外 VLM 计算；E03 历史批次仍生成 success_criteria.md，文件工具读取限于 memory，本次不生成该文件。没有重复试验或条件清单单独对照，不能把 +3 局全部归因于 VLM。

核验与模型开销

160 局结果和最终原生状态一致，160 个 memory 审计通过；502 个固定源码哈希、148 个原版 memory 文件核对通过。291 项离线测试及完整 Agent 冒烟通过。

4059 条 VLM 请求审计，4050 个响应、9 个 API 错误；另有 6 次预算取消发生在请求前，缓存标为 unavailable/unknown。输入 23,192,795 tokens，输出 960,747 tokens；中位延迟 6.339 秒，p95 9.912 秒。以上不含外层 Astra 用量。
