改动范围

移除的反馈

rldx_skill / rldx_arm 不再返回 grasp_contact、grasp_obj、grasped、grasp_detected，并停止为这些报告查询模拟器接触。

完整保留任务进度

所有原生 task_progress 均保留，包括接触派生条件；没有按任务过滤进度字段。

held_apart、gripper_qpos、peak_lift、执行状态、几何查询、相机标定、本体状态、评分源码访问和历史记忆保留。

模拟器 success 和终止信号继续返回 Agent，VLA 原生成功早停保留。提示词、VLA 输入与权重、控制预算与原版一致；本次没有使用 VLM。

结果与接口核验

160局结果均匹配最后保存的原生 success，160个退出码均为0，最终协议校验通过。扫描4,343条保存观测、1,869条 VLA 动作记录，四个移除字段零命中；其中3条 VLA 记录有中断标记，episode 仍正常结束并保留在统计中。

493个冻结源码文件和148个原版记忆文件通过哈希核验；160局 memory audit 均通过。日志监控检查160份 launcher 日志，未记录显存不足或崩溃告警。

接触派生的任务判据和夹爪宽度启发式仍可用。这项实验评估的是 VLA skill 的显式反馈，不声称移除了所有接触相关信息。
