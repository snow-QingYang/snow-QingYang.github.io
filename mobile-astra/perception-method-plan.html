RPent 感知：四类信息与对应接口

back_project_batch 和 query_world_map 都是几何查询。前者从像素查三维点，后者从空间范围查点簇。点簇没有物体语义标签，具体是什么仍需 Agent 结合图像判断。

信息类别接口 / 字段提供什么
本体状态view_env_state().state末端位姿、夹爪开度、底盘位姿。来自模拟器机器人状态。
视觉语义view_env_state() 的 RGB 图像Agent 看图判断物体身份、外观与关系。当前没有独立的 segment / locate 工具。
几何back_project_batchAgent 选图像像素 → 查询对应三维坐标。
query_world_map按高度、XY 范围 → 查询三维点簇及其范围。两者均使用模拟器深度与相机标定。点簇不一定对应一个完整物体。
交互反馈rldx_skill / rldx_arm
move_to / navigate_to		抓取接触、夹爪受阻、到位距离、底盘卡住等。grasp_contact 来自模拟器抓取判定；held_apart / stuck 是启发式。没有通用全身碰撞查询。

运动之后，也会返回感知吗？

会。框架在动作后自动附带最新 RGB 图像、机器人状态和动作结果，所以不必每次额外调用 view_env_state。

物体三维点和点簇仍需调用 back_project_batch 或 query_world_map 查询；运动不会自动返回这些结果。

看图认物体 → 查询几何位置 → 执行动作 → 看新图像与反馈。

另外，success / task_progress 是环境提供的任务判定与进度真值，单独标记。工具的 ok=true 不统一表示“抓到了”或“任务成功”。
