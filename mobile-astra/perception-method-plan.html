RPent 感知与真值：接口速查

back_project_batch 和 query_world_map 都是几何查询。前者从像素查三维点，后者从空间范围查点簇。点簇没有物体语义标签，具体是什么仍需 Agent 结合图像判断。

信息类别接口 / 字段提供什么
本体状态view_env_state().state末端位姿、夹爪开度、底盘位姿。来自模拟器机器人状态。
视觉语义view_env_state() 的 RGB 图像Agent 看图判断物体身份、外观与关系。当前没有独立的 segment / locate 工具。
几何back_project_batchAgent 选图像像素 → 查询对应三维坐标。
几何query_world_map按高度、XY 范围 → 查询三维点簇及其范围。两者均使用模拟器深度与相机标定。点簇不一定对应一个完整物体。
抓持反馈rldx_skill / rldx_arm
grasp_contact / grasp_obj		grasp_contact：调用结束时的模拟器抓取判定。
grasp_obj：本次调用最近识别到的任务物体名，结束时可能已经放开。held_apart 是夹爪受阻的启发式判断。没有通用全身碰撞查询。
运动反馈move_to / move_delta
navigate_to
rldx_skill / rldx_arm		final_dist：末端距指定 XYZ，或底盘距指定 XY 的距离。
moved：navigate_to 前后底盘的平面直线位移。
base_drift：VLA 调用前后底盘的平面位移。距离单位为米，来自机器人真实位姿；位移不是累计路程。stuck 是启发式，base_drift 不一定代表异常。

task_progress：子条件、状态、计数和距离，例如 pan_on_stove、door_closed、washed_time、dist。来自环境成功判定代码的内部变量；字段随任务变化，部分任务返回空字典。
成功判定规则read_text_file
读取本次运行的
success_criteria.md		任务的 _check_success() 及部分辅助函数源码：条件组合、代码中的阈值与计数要求。规则说明怎样才算成功；task_progress 提供当前进度。

怎么读取动作反馈？

动作返回自动附带 RGB 图像、机器人状态、任务进度；具体动作字段在 log.result 中，例如 log.result.final_dist。也可用 view_env_state() 查看最近一次动作结果。

“目标”是 Agent 传入的坐标。Agent 看图选像素 → 用 back_project_batch 查三维表面点 → 选择目标并调用 move_to(xyz)。final_dist 衡量末端距这个坐标有多远；navigate_to(xy) 对底盘同理。动作方法不会自动查询目标物体的真实位置。选错坐标，也可以准确到达；距离小不代表抓对了。

物体三维点和点簇仍需通过几何查询获取。moved、base_drift 只比较底盘起终点，不需要物体位置或目标坐标，也不能说明碰到了什么。

工具的 ok=true 不统一表示“抓到了”或“任务成功”；任务是否完成以环境的 success 为准。
