HarnessVLA：真值移除与替代

逐项验证模拟器真值对 HarnessVLA 的贡献，并评估可用于真机的替代方案。

当前基础：RPent / RoboCasa · GPT-6-Astra xhigh · 32 个 composite 任务 × seeds 1–5

实验动机 · Motivation

原版 HarnessVLA 可直接读取模拟器提供的三维几何、任务进度和交互反馈。真机上，这些信息往往需要测量或估计，也会有误差。因此，我们要弄清：当前成功率有多依赖这些真值，哪些信息最关键，以及用传感器或感知模型替代后能保留多少能力。

通过“原版 → 逐项去掉 → 估计替代”对照，同时查看成功率和 Planner 的失败／修复过程，找出从模拟器走向真机需要补齐的信息。

怎么验证

先沿着实际接口查清楚：哪些信息进入 Agent 上下文，哪些只在控制器或 VLA 内部使用，哪些仅用于最终评分。然后每次改一类信息，比较原版、去掉、替代三个设置。

01 / 原版

建立参照

保留现有真值，记录成功率、动作轨迹和 Agent 实际看到的信息。

02 / 去掉

看它是否重要

逐项切断信息来源，检查返回值、文件读取和内部控制是否仍泄露同类信息。

03 / 替代

看估计能否补回来

用 RGB / RGB-D、机器人传感器或视觉判断代替直接读取模拟器状态。

模拟器真值仍可用于独立评测。需要限制的是被实验移除的信息进入 Agent 或执行过程的通道。
