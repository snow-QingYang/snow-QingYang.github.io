Agent 方法调用手册

从图像定位，到机械臂控制、VLA 执行与任务结束。这里列出当前 RoboCasa 集成公开给 Agent 的全部工具，以及它们的输入、输出和运行限制。

18 个默认注册17 个本次评测可用1 个可选原生动作工具离线单文件 · 无外部依赖
METHOD INDEX
view_env_stateback_project_batchquery_world_mapmove_tomove_deltarotate_pitchset_gripperreleasescripted_graspmove_basenavigate_torldx_skillrldx_armread_text_filewrite_text_filelist_dirfinishresetexecute_action

Agent 输出的是工具名称和 JSON 参数。 工具执行后返回结构化结果，部分工具还返回相机图片，Agent 再据此选择下一次调用。

默认注册的 reset 在评测中会被拒绝；execute_action 只有显式开启才注册。下面展示全部 19 个接口，避免把“注册可见”与“本次允许执行”混为一谈。

这批 Astra 评测的实际 VLA 配置40 chunks × 8 actions = 每次调用最多 320 个仿真动作步

接口本身的 max_chunks 默认是 70，但本次 RLDX_MAX_CHUNKS=40 覆盖传参；RLDX_ACTION_STEPS_PER_CHUNK=8 与 RLDX_SETTLE_PATIENCE=999 也会覆盖对应参数。实际 prompt 始终采用环境完整 task_language。该预算不是整个任务的步数上限。

观察与定位

view_env_state

评测可用

读取最新或指定步骤的观测，查看三路相机、机器人状态与任务进展。

参数类型默认值含义
stepinteger / nullnull观测步骤编号；null 为最新
读取已记录的状态，不会推进仿真。step=0 表示初始状态；省略时读取最新状态。

返回 图像、state、task_language、task_progress、success、上次动作日志。

查看调用示例与原始 schema
CALL EXAMPLE
{
  "method": "view_env_state",
  "arguments": {
    "step": 0
  }
}

展示 method 名称及 arguments；具体传输封装由框架处理。示例参数仅用于说明接口。

    "step": {
      "anyOf": [
        {
          "type": "integer"
        },
        {
          "type": "null"
        }
      ],
      "default": null,
      "description": "Step number; 0 = initial. Null = latest.",

rotate_pitch

评测可用

参数类型默认值含义
target_pitchnumber0.6分步发送的旋转控制参数，见实现说明
grippernumber1+1 闭合 / -1 打开；支持字符串时可用 hold
