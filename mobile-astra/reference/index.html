从实际案例核对

PanTransfer 成功案例的“信息清单”可以直接跳到 Agent 实际收到的任务进度、几何查询和抓持／到位反馈。字段存在于模拟器内部与它实际进入 Agent 上下文，是两个需要分别核对的问题。

E08：Agent 实际知道的相机信息

Planner 收到 agentview、navview、wrist 的 RGB，以及视角名称、用途和图像标签。agentview 实际对应左侧观察相机；navview 位于底盘；wrist 是随夹爪移动的腕相机。未提供数值相机内参、外参／pose 或 FOV。calibration_frame 是标签，不表示已传入标定矩阵。

VLA 使用另一组三视图：左侧、右侧、腕相机的 256×256 RGB。相机 metadata、深度、world map 和导航地面 overlay 仍由后台生成保存，E08 的观测接口不返回它们；全量轨迹未观察到文件或 shell 读取。详细说明 · 完整信息范围
